# Энсиэли · Биология Намского улуса

Образовательный сайт о флоре и фауне **Намского улуса** (долина Энсиэли, Центральная Якутия).
Светлый интерфейс в духе Google Gemini: белый фон, крупные прямоугольные кнопки, мягкие тени,
градиентные акценты и звуковое сопровождение каждого действия (звук синтезируется в браузере,
аудиофайлы не нужны).

## Меню — три кнопки

Занятие построено по шагам, ничего лишнего:

| | Кнопка | Что внутри |
|---|---|---|
| 1 | 🦌 **Знакомство с животными** | 22 вида улуса: кто такой хорь, кто летает над Леной, что растёт в аласах. Фильтр «Животные и птицы / Растения и грибы», рассказ по пунктам, кнопка «🔊 Прочитать вслух», листание ← → |
| 2 | 🃏 **Закрепление** | 20 карточек «термин — определение» с переворотом, отметкой «знаю» и перемешиванием |
| 3 | ❓ **Викторина** | **Начинается сразу**, без настроек: 10 случайных вопросов из 23, подсказка, объяснение после ответа, итог с разбором ошибок |

Управление с клавиатуры: `1–4` или `А/Б/В/Г` — ответить, `H` — подсказка, `Enter` — далее,
`Space` — перевернуть карточку, `←/→` — листать, `Esc` — вернуться в меню.
Звук включается и выключается кнопкой 🔊 в шапке (состояние запоминается).

## Редактирование заданий ✏️

Кнопка **«Редактировать тексты заданий»** под тремя главными (или значок ✏️ в шапке) открывает редактор
с тремя вкладками: **Вопросы · Виды · Карточки**.

Можно поменять любые слова:

- **вопрос** — текст, все четыре варианта, какой из них правильный (кнопка с буквой), подсказку и объяснение;
- **вид** — название, подпись, эмодзи и рассказ (каждая строка текста становится отдельным пунктом);
- **карточку** — термин, определение и метку.

Правки применяются мгновенно — они сразу видны в знакомстве, закреплении и викторине — и сохраняются
в браузере. Исходные тексты не портятся: у каждого блока есть **«Отменить правки»**, а сверху —
**«Вернуть исходные тексты»**. Для переноса на другой компьютер есть **«Скачать правки (JSON)»**
и **«Загрузить правки»**.

Защита от ошибок: пустой текст не сохранится, повторяющиеся варианты ответа отклоняются —
об этом скажет всплывающее сообщение.

## Запуск и тесты

```bash
npm start     # python3 -m http.server 8080 --bind 0.0.0.0
npm test      # 28 проверок: данные, слой правок и реальные клики по интерфейсу (jsdom)
```

Сайт статический — можно просто открыть `index.html` в браузере.

## Структура

```
index.html              каркас: шапка (назад · звук · редактор) и контейнер экрана
assets/styles.css       светлая тема в стиле Gemini
assets/js/data.js       исходные тексты: вопросы, виды, карточки, темы
assets/js/content.js    слой правок: читает исходники + изменения из localStorage
assets/js/sound.js      синтез звуков на Web Audio API (клик, верно/неверно, победа…)
assets/js/store.js      статистика и озвучивание текста (Web Speech API)
assets/js/app.js        три режима, редактор, роутер по хешу
tests/app.test.mjs      тесты на jsdom
```

Чтобы добавить вопрос с нуля, допишите объект в `QUESTIONS` в `assets/js/data.js`
(`id`, `topic`, `text`, `options`, `answer`, `hint`, `explain`) — либо поправьте похожий прямо в редакторе.
