# Энсиэли · Биология Намского улуса

Интерактивный образовательный сайт о флоре и фауне **Намского улуса** (долина Энсиэли, Центральная Якутия).
Светлый интерфейс в духе Google Gemini: белый фон, скруглённые карточки, мягкие тени, градиентные акценты
и звуковое сопровождение каждого действия (синтезируется в браузере, без аудиофайлов).

## Режимы

| Режим | Что делает |
|---|---|
| 🏠 **Главная** | Обзор режимов, ключевые цифры (36 видов млекопитающих, 3 завезённых) и текущая точность |
| ❓ **Викторина** | 23 вопроса с выбором раздела, тем и количества вопросов. Подсказка, объяснение после ответа, разбор ошибок в конце |
| ⏱️ **Спринт 60 секунд** | Ответы на скорость, автопереход к следующему вопросу, рекорд сохраняется |
| 🃏 **Карточки** | 20 терминов (тебенёвка, алас, сардаана, куба…) с переворотом карточки и отметкой «знаю» |
| 📖 **Справочник** | 22 вида растений и животных с фильтрами и поиском |
| 📊 **Прогресс** | Точность, серии, рекорды, разбивка по темам и рекомендация, что повторить |

**Управление с клавиатуры:** `1–4` или `А/Б/В/Г` — ответить, `H` — подсказка, `Enter` — далее,
`Space` — перевернуть карточку, `←/→` — листать карточки, `Esc` — закрыть окно.

**Звук:** переключается в левом меню («Звуковые эффекты») и кнопкой 🔊 в шапке; состояние запоминается.
Отдельно можно включить озвучивание вопросов («Читать вслух», Web Speech API).

## Запуск

Сайт статический, сборка не нужна:

```bash
npm start          # python3 -m http.server 8080 --bind 0.0.0.0
# или просто откройте index.html в браузере
```

## Тесты

```bash
npm install        # поставит jsdom (dev-зависимость)
npm test           # 28 проверок: данные + реальные клики по интерфейсу в jsdom
```

Тесты (`tests/app.test.mjs`) запускают приложение в настоящем DOM и имитируют действия пользователя:
переходы по меню, фильтры тем, ответ мышью и с клавиатуры, блокировку повторного ответа,
запись статистики в `localStorage`, переворот карточек, поиск и модалку справочника, сброс прогресса.

## Структура

```
index.html              разметка каркаса (меню, шапка, контейнеры)
assets/styles.css       светлая тема в стиле Gemini
assets/js/data.js       вопросы, карточки, справочник, темы
assets/js/sound.js      синтез звуков через Web Audio API (клик, верно/неверно, победа…)
assets/js/store.js      прогресс в localStorage + озвучивание (Web Speech API)
assets/js/app.js        режимы, роутер по хешу, викторина и спринт
tests/app.test.mjs      тесты на jsdom
```

## Как добавить свой вопрос

В `assets/js/data.js` допишите объект в массив `QUESTIONS`:

```js
{
  id: 'q24',
  topic: 'birds',                       // id темы из TOPICS
  text: 'Текст вопроса?',
  options: ['Вариант А', 'Вариант Б', 'Вариант В', 'Вариант Г'],
  answer: 2,                            // индекс правильного варианта (0…3)
  hint: 'Подсказка для ученика.',
  explain: 'Объяснение правильного ответа.'
}
```

Темы, карточки и виды справочника добавляются аналогично — в `TOPICS`, `CARDS` и `SPECIES`.
