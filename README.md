# Интерактивные задания · Намский улус · 5 класс

Простые интерактивные задания по курсу «Моя Родина — Намский улус» и по природе улуса.
Интерфейс построен по школьной схеме:

**заголовок → короткая инструкция → задание → варианты → «Проверить» → результат.**

Ученик видит на экране только текущее задание: без панелей, боковых меню, счётчиков опыта
и декоративных элементов. За 2–3 секунды понятно, что делать и куда нажимать.

Вопросы викторины «Моя Родина — Намский улус» соответствуют плану урока 1: малая и большая
родина, село Намцы, расстояния до Якутска и Москвы, река Лена, ведение календаря погоды.

Рисунки нарисованы в едином стиле школьного атласа и лежат в `assets/img/` — по картинке
у каждого из 26 объектов: животные (лебедь-кликун, орлан-белохвост, утки, хищные птицы, косуля,
лось, волк, бурый медведь, соболь, степной хорёк, ондатра, заяц, полёвка, якутская лошадь
и корова), растения (лиственница, сосна, сардаана, иван-чай, осока, брусника, маслята)
и местности (долина Энсиэли, река Лена, алас, село Намцы). Если у объекта картинки нет,
вместо неё показывается эмодзи, поэтому задание работает целиком.

## Задания

На старте — список из четырёх заданий:

| | Задание | Что делает ученик |
|---|---|---|
| 1 | **Животные, растения и местности** | Знакомство: 26 карточек с рисунками, фильтр «Животные / Растения / Местности», рассказ и чтение вслух |
| 2 | **Моя Родина — Намский улус** | 10 вопросов к уроку: малая и большая родина, село Намцы, Якутск, расстояния, река Лена, долина Энсиэли, календарь погоды |
| 3 | **Закрепление: угадай по картинке** | 10 картинок без подписей: «Как называется это животное / растение / место?» и четыре названия на выбор |
| 4 | **Природа улуса** | 10 вопросов о флоре и фауне долины Энсиэли (короткие вопросы и короткие варианты) |

### Как устроено закрепление

Вместо слов — большая картинка, под ней вопрос и четыре названия. Подпись у картинки пустая,
чтобы она не подсказывала ответ. Варианты подбираются из той же группы, что и объект на
фотографии: к животному — животные, к растению — растения, к местности — местности.
Проверка, подсказка и экран результата работают ровно так же, как в викторине;
в разборе ошибок вместо текста вопроса показывается сама картинка и правильный ответ.

### Как устроена викторина

- «Задание 3 из 10» и полоса прогресса — больше ничего лишнего.
- Четыре крупных варианта ответа, выбранный хорошо виден.
- Кнопка **«Проверить»** не активна, пока не выбран ответ.
- Правильно → зелёное сообщение **«Правильно!»** и короткое объяснение, затем **«Следующее задание →»**.
- Неправильно → красный вариант с ✕ и сообщение **«Неправильно. Попробуй выбрать другой вариант.»**
  Ошибочный вариант закрывается, можно выбрать другой. В результат идёт ответ с первой попытки.
- Ссылка **«Нужна подсказка»** — по желанию.
- В конце: **«Отличная работа! 9 из 10 правильных ответов»**, полоса, процент, две кнопки —
  «Пройти ещё раз» и «К списку заданий», плюс короткий разбор ошибок.

Клавиатура: `1–4` — выбрать ответ, `Enter` — проверить или перейти дальше, `H` — подсказка,
`←` `→` — листать рассказы, `Esc` — к списку заданий.
Звук включается и выключается круглой кнопкой-иконкой динамика вверху.

## Для учителя

Ссылка **«Для учителя: изменить задания»** внизу стартового экрана открывает редактор
(вкладки: Вопросы · Рисунки и рассказы). Можно менять любые слова: текст вопроса,
варианты, какой вариант правильный, подсказку, объяснение, набор заданий, а также название
объекта, подпись, файл картинки и рассказ. Название из справочника — это и есть ответ
в закреплении, поэтому его правка сразу меняет варианты в угадайке.

### Свои картинки

Рисунок может оказаться не тем — тогда его можно заменить своим, ничего не пересобирая.
Во вкладке **«Рисунки и рассказы»** у каждого объекта есть кнопка
**«Загрузить свою картинку»**: выбираете файл (JPG, PNG, WEBP), он сжимается до 900 px
и показывается везде — в знакомстве, в угадайке, в редакторе.

Своя картинка хранится **в этом браузере** (IndexedDB), переживает перезагрузку страницы
и работу без интернета, никуда не отправляется. Кнопка **«Убрать свою картинку»**
возвращает рисунок из папки `assets/img`. Кнопка **«Вернуть исходные тексты»**
свои картинки не трогает.

Важно: своя картинка видна только на том компьютере, где её загрузили.
Чтобы её увидели все, нажмите **«Скачать картинку»** — файл сохранится под именем
из поля «Файл рисунка» — и положите его в папку `assets/img/` (см. ниже про публикацию).

Правки сохраняются в браузере и сразу видны ученику. Исходные тексты не портятся:
у каждого блока есть «Отменить правки», сверху — «Вернуть исходные тексты»,
а для переноса на другой компьютер — «Скачать правки» и «Загрузить правки» (JSON).
Пустой текст и повторяющиеся варианты не сохраняются.

## Публикация на Vercel

Сайт полностью статический: сборка не нужна, достаточно отдать папку проекта.

1. Залейте репозиторий на GitHub и подключите его в Vercel → **Add New… → Project**.
2. Framework preset — **Other**, команды сборки и вывода оставьте пустыми.
3. Deploy. Дальше каждый `git push` публикует новую версию.

Тексты и картинки, которые учитель менял в браузере, на сервер не уходят — они живут
в его браузере. Чтобы правка стала общей для всех:

- **текст** — нажмите «Скачать правки», пришлите файл, изменения вносят в `assets/js/data.js`;
- **картинка** — нажмите «Скачать картинку», положите файл в `assets/img/` под тем же именем,
  которое указано в поле «Файл рисунка», и запушьте; после этого свою локальную копию
  можно убрать кнопкой «Убрать свою картинку».

После изменения `assets/js/*` или `assets/styles.css` поднимите версию в `index.html`
(строки вида `?v=20260910e`), иначе браузеры учеников останутся на старой копии.

## Запуск и тесты

```bash
npm start     # python3 serve.py 8080 — сервер без кэша, изменения видны сразу
npm test      # 47 проверок: данные, слой правок, свои картинки и реальные клики по интерфейсу (jsdom)
```

Сайт статический — можно просто открыть `index.html` в браузере.

## Структура

```
index.html              шапка («Назад», название, звук) и контейнер задания
assets/styles.css       одна компонентная система: заголовки, варианты, кнопки, сообщения
assets/js/data.js       исходные тексты: 33 вопроса в двух наборах, 26 объектов с картинками
assets/img/             рисунки: 26 JPEG шириной ~900 px (~1,8 МБ всего)
assets/js/pics.js       свои картинки учителя: IndexedDB + сжатие до 900 px
assets/js/content.js    слой правок: исходники + изменения из localStorage
assets/js/sound.js      звук на Web Audio API (клик, верно, ошибка, победа)
assets/js/store.js      статистика и чтение текста вслух
assets/js/app.js        экраны: список заданий, викторина, знакомство, угадайка по картинке, редактор
tests/app.test.mjs      тесты на jsdom (свои картинки проверяются на настоящем IndexedDB)
serve.py                статический сервер с заголовками no-cache (чтобы правки было видно без Ctrl+F5)
```

Новый вопрос добавляется в `QUESTIONS` в `assets/js/data.js`
(`id`, `set` — набор заданий, `topic`, `text`, `options`, `answer`, `hint`, `explain`)
или правкой похожего вопроса прямо в редакторе.
